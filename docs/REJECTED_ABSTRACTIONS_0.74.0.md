# v0.74.0 Rejected Abstractions

Status: implementation stop reached; pentest required before tagging.

## Generating Runtime APIs From Fetched HTML

The upstream document is not a stable machine schema and is outside the build
trust boundary. v0.74 commits reviewed normalized evidence and treats drift as
a stop; fetched HTML never generates published Rust code.

## Treating Every Deprecation As An Operation

Deprecated server-IP aliases and deprecated fields appear inside active
operation sections. Counting them as independent operations would inflate the
API claim and invite obsolete routes. Only HTTP operation headings are rows;
aliases and fields remain excluded policy evidence.

## Implementing Legacy Robot Storage Boxes

All 16 headings are deprecated upstream and have a supported Console API
replacement already implemented in this provider. Adding both surfaces would
duplicate models and preserve weaker legacy behavior.

## One Robot Milestone

Robot spans authentication lockout, form encoding, unusual errors, quotas,
empty bodies, destructive changes, and billable ordering. The lock assigns
small endpoint-family milestones instead of creating one unreviewable module.

## YAML Response Support

The official service can select YAML by path suffix, but the SDK plan uses the
source-locked JSON boundary. A second parser increases attack surface without
adding endpoint coverage.
